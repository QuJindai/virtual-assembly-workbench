# 尺寸工程使用说明 · v0.2

点击主窗口“尺寸工程”打开工作区，选择移动/实测与参考/名义资源，选择工具并输入参数。“新增合成示例”会新增两件明确标注的示例，填入可计算的方案，不覆盖已有数据。

## 工具与输入

| 工具 | 操作 | 应检查的结果 |
|---|---|---|
| 3-2-1 基准 | 依次选 A1、A2、A3、B1、B2、C1 六对点；可搜索测点编号 | 主基准约束 Z、次基准约束 Y、第三基准约束 X；点序决定方向。检查分层残差后显式应用 |
| RPS 约束定位 | 配对点、逐点世界坐标法向和权重；勾选允许变化的 DOF，设置转动中心与行程 | 六个调整量、前后残差、Jacobian 秩、行程触边；约束不足会拒绝计算 |
| 刚体装调建议 | 在 RPS 输入上给定沿每行法向的目标偏置 | 预测满足目标的刚体位姿，不计算铰链载荷、接触力、钣金弹性或回弹 |
| 几何特征拟合 | 选择同一特征的表面/孔缘点，指定平面、直线、圆、球或圆柱；可比较参考特征 | 尺寸、方向和拟合误差。平面比较法向偏移，线/圆柱比较无限轴线距离；不把任意采样中心差当作位置度 |
| 几何候选识别 | 平面或圆，内点阈值、最少点数、候选上限与随机种子 | 原始内点编号和重拟合结果；需人工确认几何与工艺语义 |
| 间隙与面差 | 选同截面两侧对应边缘点，指定垂直的正向间隙轴和面差轴 | “移动−参考”的有符号投影，保留沿缝切向错位；负投影不能单独证明实体干涉 |
| 截面 | 平面经过点、法向、点数上限；云数据还需薄层全厚度 | CAD 曲线有限采样、网格真实交线端点或现有云薄层点；输出不是拓扑排序后的封闭轮廓 |
| CAD 实体干涉 | 两个有效闭合 CAD，长度容差 | 分离/接触/干涉、最小距离、公共体积及体积判定容差。开放曲面、点云和内核失败不作实体判定 |
| 测点坐标公差 | 同范围内带编号数据；控制名称、测点、方向、偏差上下限 | 满足/超限/缺测/未判及覆盖率；这是明确坐标限值筛查，不是完整 GD&T 或放行结论 |

配对工具支持搜索明确测点编号；无编号资源使用 `#1` 起算的原始行号。特征选区支持 `RING_*` 前缀或逗号分隔编号，留空为全部。不要把稀疏孔中心位置当作孔缘点去拟合孔径。截面可加入资源后继续明确选点；不自动猜测两侧边缘的对应关系。

## 原始 eMMA 限值

先在主窗口导入完整 eMMA CSV，选择同计划/零件的实测与名义数据。在坐标公差页“导入控制CSV”选择该原文件，程序读取名义 `MPT` 记录的 `TolAxisPosX/Y/Z.LowerToleranceValue/UpperToleranceValue`，自动启用名义资源局部方向。界面提供原文件 mm/m 单位选项，并从名义资源的 eMMA 导入历史预填；读取后统一转换为 mm。请在导入控制前核对原文件单位。

单侧空白表示单侧约束，双侧空白不导入为有判定项；显式 0/0 保留为零宽区间。缺少实测或名义 XYZ 的控制保留为缺测，不补零或冒充通过。对于与限值仅存在浮点舍入尺度非零差异的值，保留原数值和公差，标记为未判并说明数值边界原因；精确相等仍按闭区间处理。舍入敏感性估计不是仪器测量不确定度，也不扩大工艺公差。其他特征公差字段不自动映射为坐标控制。数据已旋转时，应使用随名义坐标系旋转的方向；自定义世界坐标量规可关闭该选项。

也可使用控制表：`name,point_id,nx,ny,nz,lower_mm,upper_mm`。每个方案最多 50000 项；用户仍需确认原导出字段、工艺基准与单位是否适用于当前检测任务。

## 保存、重算与导出

运行计算不会移动零件。3-2-1/RPS/装调结果检查后点击“应用装调 / 基准变换”，再重测。修改输入会清除可用结果；导出及应用还会检查几何、测点编号和位姿指纹。不能把旧结果用于已改变的模型。

“保存方案”输出 JSON，“历史方案→载入并重算”在当前几何上重新计算；“导出工程报告”输出完整 HTML、JSON 和 CSV。界面最多显示前 2000 行，报告保留所有行。每次导出建立独立目录，避免覆盖已有文件。

包含尺寸工程历史的 `.vaw` 使用格式版本 3，需要 v0.2 或更新程序读取；完整历史单独压缩存储，展开最多 128 MiB，整个工程仍受 768 MiB 限制。v0.2 可打开原版本 1/2 工程，普通工程继续使用原格式。

```bash
# 打开并计算圆特征示例
python -m assembly_workbench --engineering-demo feature
# 含九类工具的已知答案自检、报告与工程重算
python -m assembly_workbench --self-test artifacts/self-test
# 在工程中的第1/2个资源上重算方案，输出目录必须不存在
python scripts/validate_engineering.py --project part.vaw --recipe recipe.json --output private-results
# 私有文件验证：原始XYZ坐标限值、导出QC差值独立核对、保存/恢复/重算
python scripts/validate_engineering.py --emma-folder PRIVATE_INPUT --output NEW_PRIVATE_OUTPUT
```

所有输出可能包含输入编号、坐标和公差；测试生产数据时使用私有目录。本次公开示例与 CI 仅含合成数据。CATPart/CATProduct 需在 CATIA 或合规转换器导出 STEP/IGES；本升级未增加专有格式转换器。
