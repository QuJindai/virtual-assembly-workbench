虚拟装配工作台 v0.2.0 · 尺寸工程预览版

在发行页下载 Windows x64 ZIP，完整解压后运行 `AssemblyWorkbench.exe`；无需另装 Python，运行时离线。源代码、研发方法记录和操作指南见仓库。

- 新增可操作的中文“尺寸工程”工作区：3-2-1 基准、RPS 约束定位、刚体装调建议，支持显式选点、DOF、法向、权重、转动中心和行程，先查看调整量再应用。
- 新增平面、线、圆、球、圆柱拟合及有界平面/圆候选，保留内点、残差和病态性检查。
- 新增配对边缘的有符号间隙/面差、CAD/网格截面和云薄层；有效闭合 CAD 用原始 BRep 公共体积判断干涉。
- 新增逐点坐标限值及原始 eMMA XYZ 公差导入，区分超限/缺测/未判，保留名义坐标系方向。
- 完整方案、几何指纹和结果保存进版本3工程，可载入重算并导出 HTML/JSON/CSV；原版本1/2工程可继续打开。
- 实际使用研发雷达核查复用候选，并对照 PolyWorks 2026、SciPy、Open3D、OCCT 官方资料记录本轮技术选择。运行依赖保持锁定。

发布由 Linux、Windows 数值与真实 Qt 工作流验证把关；Windows 打包 EXE 运行九类工程工具的已知答案自检、工程恢复与重算。`self-test.json` 保留计算证据，`SHA256SUMS.txt` 校验便携 ZIP。`engineering-windows.png` 和 `engineering-linux.png` 是实际工程窗口；配套 viewport PNG / render JSON 保留原生 VTK 帧缓冲与计算结果。

公开程序和 CI 仅含合成数据，生产样本与私有报告不发布。此版不包含认证 GD&T、CATIA 原生转换器、CMM 控制、弹性/接触力学或 AI 变形预测；几何候选不等于工艺特征确认，坐标筛查不构成放行结论。没有与原软件或 PolyWorks 的同条件实机基准，不能宣称全面超越。
